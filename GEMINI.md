# compassion compass: rules for Gemini and every other AI working on this repo

These rules apply to Gemini (Gemini Code Assist and Gemini CLI read this file automatically), GitHub Copilot, Claude, and any other AI or coding agent that reads or changes this project. Read this before doing any work. If older instructions conflict with this file, this file wins.

## Why it exists (read first)

compassion compass is a free guide for people who are homeless or struggling in the Portland metro area. They use it to find where to eat, how to get money or benefits, where to sleep, and how to get by. It is built and kept free by one person.

Judge every change by one question: could someone with a cheap phone, little battery or data, and no one to ask find real help through this and reach it? Wrong or missing information can cost a person a meal or a bed. Accuracy, working phone numbers and addresses, "Always call first", plain language, and all 7 languages (English, Spanish, Russian, Ukrainian, Vietnamese, Chinese, Somali) matter more than polish.

## Rules

1. The name is always written in lowercase: compassion compass.
2. Nothing is published, deployed, uploaded, committed, pushed or merged without the owner's explicit go, every time. A go for one change does not cover the next.
3. The compass icon is the mascot. Use it exactly as it is: never redrawn, recolored, restyled, stretched or replaced, in the app, videos or promo material.
4. Every change to the look, design or content of the site, videos or promo material is approved by the owner first. Propose it, wait for a yes, then build it.
5. No 211 button and no 211 call link.
6. Portland metro only. No listings outside the metro area.
7. Keep the 8 categories in the owner's order and with these titles: Shelter, Food, Medical, Crisis, Recovery, Daily Needs, Monetary Resources, Miscellaneous. (Their keys in the code are shelter, food, medical, crisis, recovery, daily, money, misc.) Do not reorder, rename, add or remove categories.
8. "Always call first" appears on every listing, on every language page.
9. The scheduled data refresh changes only compass-data.json, never the HTML pages.
10. Keep it free: nothing that costs users money, and no accounts, logins, paywalls or sign-up walls for people looking for help.
